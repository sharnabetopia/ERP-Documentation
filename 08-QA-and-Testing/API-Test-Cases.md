# API Test Cases

Document status: Draft v0.1 (Stage 3 part 1). Proposed. Test cases are written, **none has been executed**. Every Actual Result is blank and every status is Not Run.
Contract tests from the API conventions, one role-based permission test per permission code used by the API, and one test per error code in the catalogue. Business behaviour of each endpoint is tested by the functional cases linked through the FR column of the [API Documentation](../04-System-Architecture/API-Documentation.md) (the same cases run at API level). Priority P0 to P2 follows the [Test Strategy](Test-Strategy.md) definitions. Severity is the impact if the test fails. Steps are separated by line breaks.

Test cases in this file: 186. IDs run from TC-0296 to TC-0481 (IDs are shared across all files, so ranges may be non-contiguous).
