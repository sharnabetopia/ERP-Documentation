# Regression Test Suite

Document status: Draft v0.2 (Phase 2 remediation, 2026-11-11). **Cases are written, none has been executed.** Every Actual Result is blank and every status is Not Run.
This file defines the dedicated regression suite that the audit found missing (no case carried the Regression type). It has two parts. Part 1 lists seven suites built from existing test case IDs, which stay unchanged. Part 2 holds 35 new cases of type Regression, TC-0750 to TC-0784, written for the behaviour fixed in Phase 2.
Entry criteria for a regression run: the build passes lint, typecheck and unit tests. Exit criteria: no open Critical or High failure in any suite. A failure in the RBAC or financial suite blocks release.
