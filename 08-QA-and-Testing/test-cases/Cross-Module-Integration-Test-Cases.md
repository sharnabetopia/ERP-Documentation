# Cross-Module Integration Test Cases

Document status: Draft v0.1 (Stage 3 part 1). Proposed. Test cases are written, **none has been executed**. Every Actual Result is blank and every status is Not Run.
Covers the 15 system invariants (INV-01 to INV-15), atomic multi-module postings, module hand-offs, the 12 database constraints (DBC-01 to DBC-12), and technical and non-functional requirements that no functional case reaches (selected NFR and TR). Priority P0 to P2 follows the [Test Strategy](../Test-Strategy.md) definitions. Severity is the impact if the test fails. Steps are separated by line breaks.

Test cases in this file: 61. IDs run from TC-0259 to TC-0521 (IDs are shared across all files, so ranges may be non-contiguous).
