# Security Test Cases

Document status: Draft v0.1 (Stage 3 part 1). Proposed. Test cases are written, **none has been executed**. Every Actual Result is blank and every status is Not Run.
One or more test cases for each security requirement SEC-001 to SEC-053, plus abuse-case tests for ERP fraud and misuse threats that no other test reaches (THR-012 to THR-044 subset). The approach, tools and schedule are in the [Security Test Plan](../Security-Test-Plan.md). Priority P0 to P2 follows the [Test Strategy](../Test-Strategy.md) definitions. Severity is the impact if the test fails. Steps are separated by line breaks.

Test cases in this file: 66. IDs run from TC-0193 to TC-0258 (IDs are shared across all files, so ranges may be non-contiguous).
