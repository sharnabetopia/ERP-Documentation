# Lifecycle WF-05 Plan-to-Produce Test Cases

Document status: Draft v0.2 (Phase 2 remediation). Proposed. Test design only, not executed and not approved.
Test cases: 43. ID range: TC-0835 to TC-0877.
Lifecycle under test: [WF-05 Plan-to-Produce](../../05-Workflows-and-Diagrams/Lifecycles/WF-05-Plan-to-Produce.md).
Manufacturing is release R4 and has no functional requirements yet (see [Manufacturing Test Cases](Manufacturing-Test-Cases.md)).
Requirement IDs therefore point to the existing business requirement BR-057, to the inventory, approval and ledger rules and requirements that the lifecycle relies on, and to security requirements.
Production roles do not exist in the 18 default roles. Test users with production duties hold the Department Manager role. This mapping is proposed, PENDING APPROVAL.
Tolerances, the adjustment threshold and the valuation method used as test data are test settings only. They are proposed values, PENDING APPROVAL (OQ-009, OQ-013).
Story ID is n/a because no user story exists for this lifecycle.
Actual Result is blank and every case is Not Run.
