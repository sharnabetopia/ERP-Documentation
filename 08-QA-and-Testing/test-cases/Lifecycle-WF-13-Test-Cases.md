# Lifecycle WF-13 Contract-to-Renewal Test Cases

Document status: Draft v0.2 (Phase 2 remediation). Proposed. Test cases are written, **none has been executed**. Every Actual Result is blank and every status is Not Run.
Covers the lifecycle [WF-13 Contract-to-Renewal](../../05-Workflows-and-Diagrams/Lifecycles/WF-13-Contract-to-Renewal.md) (release R3). No R3 contract functional requirements exist yet, so cases trace to BR-032, related BR, BRL, FR and SEC ids.
Values such as limits, notice period, alert intervals and cooling-off days are test configuration only. The real values are PENDING APPROVAL. Cases that rely on a proposed rule name it (WF13-R1 to WF13-R8 in the lifecycle document).
Priority P0 to P2 follows the [Test Strategy](../Test-Strategy.md) definitions. Severity is the impact if the test fails.
