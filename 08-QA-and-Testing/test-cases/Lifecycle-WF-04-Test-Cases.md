# Lifecycle WF-04 Hire-to-Retire Test Cases

Document status: Draft v0.2 (Phase 2 remediation). Proposed. **Test cases are written, none has been executed.** Every Actual Result is blank and every status is Not Run.
Test cases in this file: 49. IDs run from TC-0785 to TC-0833. Existing test case IDs are unchanged.
Source: [WF-04 Hire-to-Retire](../../05-Workflows-and-Diagrams/Lifecycles/WF-04-Hire-to-Retire.md).
Mix: 12 positive, 20 negative (permission, self-approval, maker-checker, SoD, scope), 7 boundary or edge, 6 failure and recovery, 4 end-to-end.
Values marked proposed in WF-04 (offer validity, step-up window, limit A, hold period, revocation time) are used here as test configuration only and need stakeholder approval.
Several cases test proposed rules WF04-R1 to WF04-R8, which are not yet approved BRL rules. They are marked in the Description. They cannot pass until the rule is approved and built.
No R2 functional requirement exists for recruitment, leave, attendance or exit, so those cases cite the business rule or MVP requirement that applies.
