# User Stories (MVP)

Document status: Draft v0.1 (Stage 2). Proposed.
Related: [FRS](FRS.md), [Use Cases](Use-Cases.md), [Acceptance Criteria](Acceptance-Criteria.md).

## 1. How to read this document

Each story has: ID, epic, module, role, story text, business value (the "so that" clause), priority, preconditions and dependencies, acceptance criteria in Given/When/Then, negative and edge cases, and related requirements.

| Field | Note |
|---|---|
| Positive scenario | The first G/W/T line of each story. |
| Negative scenario and edge cases | Listed in the "Negative and edge" column. |
| Related BR | Every FR in the "FR" column traces to its BR in the [FRS](FRS.md). The RTM (Stage 3) will join them. |
| Related test cases | TC IDs are assigned in Stage 3. The column is not repeated here to avoid placeholders that look like content. |
| Roles | Names follow the 18 default roles. |
| Priority | Highest priority among the linked FRs. |

Format of acceptance cells: G given, W when, T then. Multiple scenarios are separated by a line break.
