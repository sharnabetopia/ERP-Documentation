# RTM Correction Report

Phase 2 remediation, 2026-11-11. Related: [Remediation Progress](Remediation-Progress.md), [Final Revalidation Report](Final-Revalidation-Report.md), [Audit baseline](../12-Final-Audit/Final-Readiness-Assessment.md).
Evidence: the v0.1 matrix is preserved unchanged in `evidence/RTM-v0.1-before-remediation.md`.
No stakeholder approval is claimed anywhere in this report. Values marked PENDING APPROVAL are recommendations.

## 1. Root cause

The v0.1 RTM was generated by script. Its FR to NFR links and part of its FR to test case links came from a text match that treated "FR-019" as present inside "NFR-019". This put the 14 same-number links in the matrix (for example Company isolation to Dependency hygiene). It also linked tests to FRs through security requirement rows whose only reference was an NFR.
The rebuild uses word-boundary ID matching only. A relationship is accepted when an exact FR ID appears in the test case or in the row of the security requirement, database constraint or invariant that the test names. NFR links are judged by meaning and recorded with a reason.
