# Requirements Traceability Matrix (RTM)

Document status: Draft v0.1 (Stage 3 part 1). Generated by script from the requirement documents and the test case files, then checked. **Every Test Result is "Not Run" because no test has been executed.** "Covered" in this document means a test case is written and linked. It does not mean the requirement is verified.

Chain: Business Requirement, Functional Requirement, Non-Functional Requirement, Module, User Story, Use Case, API, Business Process (workflow), Test Case, Test Result.
IDs are defined in their own documents: [BRD](../02-Business-Analysis/BRD.md), [FRS](../03-Product-and-System-Requirements/FRS.md), [NFR](../03-Product-and-System-Requirements/NFR.md), [User Stories](../03-Product-and-System-Requirements/User-Stories.md), [Use Cases](../03-Product-and-System-Requirements/Use-Cases.md), [API Documentation](../04-System-Architecture/API-Documentation.md), [Workflows](../05-Workflows-and-Diagrams/Cross-Module-Workflows.md). Test case IDs use four digits (TC-0001) because the count exceeds 999.

5. Test priority is inflated: P0 361 of 553 cases. See Test Strategy section 5.
